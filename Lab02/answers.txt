If you create a constructor method to build a DVD by title then create a constructor method to
build a DVD by category. Does JAVA allow you to do this?
Yes, Java allows you to create multiple constructor methods in a class

Is JAVA a Pass by Value or a Pass by Reference programming language?
Java is a pass by value programming language

After the call of swap(jungleDVD, cinderellaDVD) why does the title of these two
objects still remain?
Java passes copies of the references (jungleDVD and cinderellaDVD) to the swap method,this change only affects the local copies of the references inside swap, and it does not modify the actual jungleDVD and cinderellaDVD references in main
-> java is a pass by value programing language
After the call of changeTitle(jungleDVD, cinderellaDVD.getTitle()) why is
the title of the JungleDVD changed?
changeTitle() works because dvd.setTitle(title) modifies the same object in memory that jungleDVD points to in main()
